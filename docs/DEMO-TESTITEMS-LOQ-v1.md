# Demo 測項與定量極限清單 v1（切片 6.1 用）

> 用途：demo/v1 的 seed TestItem 來源。定量極限（LOQ）的單位與該測項的「單位」欄相同。
> 本清單只用於展示，不是實驗室的確效數據。

## 來源標記

| 標記 | 意義 |
|---|---|
| ✔ | 直接取自公告檢驗方法原文（行政院公報／食藥署公告 PDF） |
| △ | 取自官方資料，但屬於間接來源，或版本/數值仍待確認（例如實驗室認證範圍的下限、說明會簡報、舊版方法、表格擷取時排版錯亂） |
| ○ | 沒有找到公開的公告值，先用示範暫定值。**Alan 可依實務經驗直接改數字** |

- **description 欄的寫法**：✔/△ 寫「方法＋參考編號」；○ 一律寫「示範值，非引用公告方法」。這樣學員看到時不會誤以為是官方數值。
- **基質依賴**：LOQ 依基質而不同。本表每個測項只取一個代表值，並在備註註明取自哪個基質。
